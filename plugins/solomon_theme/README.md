# Solomon Theme

A NetBox plugin that applies a hardcoded dark Material Design theme using the Solomon color palette.

**No UI controls** — the dark theme is always active and cannot be toggled by users.

## Color Palette

| Role            | Color     |
|-----------------|-----------|
| Background      | `#121212` |
| Surface         | `#1e1e1e` |
| Surface alt     | `#2c2c2c` |
| Primary         | `#03a9f4` |
| Primary light   | `#4fc3f7` |
| Primary dark    | `#0288d1` |
| On surface      | `#e0e0e0` |
| On surface dim  | `#9e9e9e` |
| Error           | `#cf6679` |
| Success         | `#66bb6a` |
| Warning         | `#ffa726` |
